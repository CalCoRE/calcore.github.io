This introductory module guides educators through the basic mechanics of Jupyter Notebooks. It covers how code cells are executed, how comments are read, and how variables are modified, serving as a gentle entry point into coding in Python and R.

**Intended Audience & Use Case:** 
Aimed at teachers, educational designers, and instructors who are completely new to programming. It is used as a foundational workshop activity to demystify Jupyter and establish basic data literacy.

### Access the Resource
*   [Interactive Intro Python Notebook (on Binder)](https://mybinder.org/v2/gh/CalCoRE/show-your-work/main?urlpath=%2Fdoc%2Ftree%2F0+-+IntroPython.ipynb)
*   [Interactive Intro R Notebook (on Binder)](https://mybinder.org/v2/gh/CalCoRE/show-your-work/main?urlpath=%2Fdoc%2Ftree%2F0+-+IntroR.ipynb)
